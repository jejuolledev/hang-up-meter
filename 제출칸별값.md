## 프로젝트 이름

Hang Up Meter

## 짧은 소개

Inspect concerning caller requests and the exact words behind them, alongside relevant official consumer guidance.

## 프로젝트 설명

Hang Up Meter helps a person pause and inspect an unfamiliar caller's request. It separates the conversation, a request assessment, and related consumer guidance. It does not authenticate the caller or establish that a call is safe.

The prototype offers three fictional samples, typed conversations, and consent-based browser transcription. Recognized speech must be reviewed and labeled because speech input does not separate speakers. Scripted examples are visibly labeled and are not API results.

## 실제 확인한 API

Decide changes the request assessment. Extract identifies exact matching words. Rerank selects from two curated FTC excerpts, and grounding compares an explicit caller claim with those excerpts. The gift-card policy flow passed a live smoke check and was verified in the browser. Commands and factual claims are treated separately.

## 측정 결과와 한계

A frozen, authored English synthetic set included 20 risk and 20 control conversations, checked at three cumulative turns each. All 20 risk cases were detected with no early alerts; one control case triggered a false warning. One response-read failure was recovered and preserved in the evaluation history. This is not independent real-world validation. A recipient-only input guard was added after this evaluation; the original false-alert result remains reported.
